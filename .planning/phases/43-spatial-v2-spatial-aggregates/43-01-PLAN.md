<objective>
Add the first two PostGIS geometry aggregates to both spatial accessors: `collect_geometries`
(`ST_Collect` aggregate -> result column `collected`, SPAT2-07) and `union_aggregate` (`ST_Union`
aggregate form -> result column `dissolved`, SPAT2-08). Both share a new internal
`_build_agg_geom_sql(agg_func, result_col, ...)` helper (mirrors Phase 42's `_build_binary_geom_sql`),
and both rely on a small GROUP-BY-aware extension to `_append_tail` (the only genuinely new
infrastructure in this phase, D-03). This is the first GROUP-BY aggregate shape in the spatial
surface: `group_by=None` -> exactly one row over the whole table; `group_by="region"` / `["region","zone"]`
-> one row per group.

Purpose: Deliver SPAT2-07 and SPAT2-08 at full sync/async parity following the established
column-only pure-builder pattern (validate_identifiers line 1 + per-builder injection test, `filter=`
only, pure `build_*_sql -> (sql, [])`, `_run`/`_arun` routing). The new GROUP-BY surface widens the
identifier-injection attack surface beyond Phase 42 (T-43-01) — every `group_by` column is now an
untrusted identifier that MUST pass `validate_identifiers` before interpolation.
Output: 1 `_append_tail` extension + 1 shared builder + 2 public builders + 4 accessor methods
(2 sync, 2 async) + SQL-shape/injection/routing tests in a new `TestAggregateBuilders` class.
</objective>
