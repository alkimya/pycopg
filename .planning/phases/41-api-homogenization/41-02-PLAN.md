<objective>
FREEZE-02: Rename the 4 N818-violating domain exceptions to the `*Error` convention as the CANONICAL
names, keep the old names alive through 1.x as deprecated aliases via PEP 562 module `__getattr__`
(D-07), update EVERY internal raise site / import / docstring reference to the new names (D-10), and
remove the `"pycopg/exceptions.py" = ["N818"]` ruff suppression from `pyproject.toml`.

This MUST be a single atomic change: the moment `DatabaseExists` etc. cease to be real names in
`exceptions.py`, `pycopg/__init__.py`'s direct `from pycopg.exceptions import DatabaseExists, ...`
would raise `ImportError` at package import time (RESEARCH Pitfall 2). So the `__init__.py` import
block, the `exceptions.py` rename + `__getattr__`, and all internal raise sites land together.

Purpose: N818 compliance + the same-class-object alias so `except OldName:` keeps working (D-07);
success-criterion #2 is relaxed to "imported/accessed" (D-08, NO catch-time metaclass hack).
Output: 4 `*Error` classes, two `__getattr__` resolvers, N818 suppression gone, all internals updated.
</objective>
