    - A module needs `__all__` if another module (or a downstream consumer) imports a symbol FROM it that the module itself imported (re-export). Under `--no-implicit-reexport`, a symbol imported into module A is NOT re-exported from A unless it is in A's `__all__`.

    - For base.py: `__all__` MUST include `Params` (imported by __init__ and used as the D-03 precedent) plus the public build helpers (`build_role_options`, `build_pg_dump_cmd`, `build_pg_restore_cmd`) that backup.py/admin.py import.
    - For exceptions.py: `__all__` MUST include every `*Error` class that other modules import (`TableNotFoundError`, `ConfigurationError`, `InvalidIdentifierError`, `DatabaseExistsError`, `ExtensionNotAvailableError`, and the renamed set from P41) plus the deprecated-alias plumbing that `__init__.py` re-exports.
    - config.py, utils.py, logging.py, queries.py, migrations.py, admin.py, backup.py, maint.py: add `__all__` covering each module's public accessor classes / helpers that `__init__.py` or siblings import.

    Do NOT add `__all__` to a module that has no cross-module re-export need if doing so would hide a symbol some consumer imports — verify against the grep graph first. This task is annotation/declaration ONLY; no behavior change.
  </action>
