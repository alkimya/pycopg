<objective>
CRUD-F01 — add a raw-SQL WHERE escape hatch (`where_sql` + `where_params`) to the five
predicate helpers `delete_where` / `update_where` / `exists` / `count` / `paginate` on BOTH
`Database` and `AsyncDatabase`, for conditions the dict `where` form cannot express.

Purpose: unblock arbitrary predicates (`age > %s AND status = ANY(%s)`,
`created_at < now() - %s::interval`) while keeping every existing signature byte-identical
under the frozen SemVer 1.0 API (C-03). All new params are keyword-only with `None` defaults.

Output: a shared `QueryMixin._resolve_predicate` guard/resolver + `where_sql`/`where_params`
wired into the five helpers (both classes), with mock, guard, injection, and live tests.
</objective>
