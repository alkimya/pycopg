<objective>
CRUD-F02 + CRUD-F03 — add the pagination family: a frozen `Page` envelope
(`rows`/`total`/`has_next`/`next_cursor`) plus two new methods on BOTH classes —
`paginate_page()` (offset → `Page`) and `paginate_keyset()` (keyset/seek → `Page`) — leaving
the existing `paginate()` untouched (frozen `list[dict]`, C-03).

Purpose: stable, index-friendly deep pagination via row-value keyset compare
`(c1, c2) > (%s, %s)`, and a typed envelope carrying `has_next` (always, cheaply) and an opt-in
`total`. The raw escape hatch from plan 01 composes onto both new methods (D-01).

Output: `Page` dataclass + `_build_keyset_where` builder + the two methods (both classes),
`Page` exported, `test_crud_v110_surface`, docs rows, and mock/injection/live tests.
</objective>
