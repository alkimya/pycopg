<objective>
Add the three pairwise (binary, 2-column) geometry-processing operations to both spatial accessors:
`union` (ST_Union, result col `union_geom`), `difference` (ST_Difference, result col `difference`),
and `intersection` (ST_Intersection, result col `intersection`). All three share one internal
`_build_binary_geom_sql(op_func, result_col, ...)` helper (Claude's Discretion — RESEARCH Pattern 1),

`AsyncSpatialAccessor` in the same change (D-11) and carries `filter=` only — no `where=` alias (D-10).

Purpose: SPAT2-01/05/06 — deliver pairwise overlay operations without raw SQL, born clean for the 1.0 freeze.
Output: 1 shared helper + 3 public builders + 6 accessor methods (3 sync + 3 async) + their SQL-shape,
injection, routing, and live-integration tests.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> build_*_sql | `table`/`schema`/`geom`/`other_geom`/`columns` are untrusted identifier strings interpolated into SQL text |
| caller -> accessor method | `filter`/`order_by` are raw SQL fragments (documented caller responsibility); `into` is whitelisted by `_check_into` |
| accessor -> PostGIS | `union`/`difference`/`intersection` SQL executed by the server; mixed-SRID surfaces as a native PostGIS error (D-06) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-01 | Tampering (T1 identifier injection) | `_build_binary_geom_sql` / build_union_sql / build_difference_sql / build_intersection_sql via `table`/`schema`/`geom`/`other_geom` | mitigate | `validate_identifiers(table, schema, geom, other_geom)` is LINE 1 of `_build_binary_geom_sql` (shared by all 3); per-builder injection test (`test_<op>_invalid_table`, `test_<op>_invalid_other_geom`) asserts `InvalidIdentifierError` before any SQL is sent — the tripwire against the v0.10.0 COPY-rewrite "guard silently vanishes" failure |
| T-42-02 | Tampering (T1 columns injection) | `columns=` list rendered by `_cols_str` | mitigate | `if columns: validate_identifiers(*columns)` immediately after line 1; columns-injection test asserts `InvalidIdentifierError` |
| T-42-03 | Tampering (T2 value injection) | binary ops have NO user values (params always `[]`); identifiers fully validated | accept | No `%s` values in the binary trio; nothing to bind. `filter`/`order_by` are documented raw-SQL caller responsibility (pre-existing contract, unchanged from buffer/transform) |
| T-42-SC | Tampering | npm/pip/cargo installs | accept | This plan installs NO packages (modifies existing source only — RESEARCH "Package Legitimacy Audit": none required); no install task to gate |
</threat_model>
