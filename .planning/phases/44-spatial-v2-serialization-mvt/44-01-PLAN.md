<objective>
Add the two scalar serialization helpers `as_geojson` (SPAT2-10) and `as_text`
(SPAT2-11) to `db.spatial.*` and `async_db.spatial.*`. Both are near-exact clones
of the existing `build_area_sql`/`build_perimeter_sql` scalar-helper pattern:
pure module-level builders returning `(sql, params)`, accessor methods that
validate `into=` then delegate to `_run`, and membership in `_SCALAR_HELPERS` so
`into="gdf"` raises.

Purpose: Users serialize geometry columns to GeoJSON text and WKT text without
raw SQL — the easy two-thirds of Phase 44, landing first so the harder `as_mvt`
(Plan 02) builds on a clean, tested surface.

Output: `build_geojson_sql` + `build_text_sql` builders, `as_geojson`/`as_text`
on both accessor classes, two `_SCALAR_HELPERS` entries, and the SQL-shape /
injection / `into="gdf"` / live-PostGIS test classes for both.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → `build_geojson_sql`/`build_text_sql` | `table`, `schema`, `geom`, and each `columns` entry are caller-supplied identifiers interpolated into the SQL string |
| caller → `as_geojson`/`as_text` accessor | `filter` is a raw SQL fragment (born-clean `filter=`, documented escape hatch); `max_decimal_digits`/`include_bbox`/`include_crs` are bound, not interpolated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-01 | Tampering (SQL injection via identifiers) | `build_geojson_sql`, `build_text_sql` (`table`/`schema`/`geom`/`columns`) | mitigate | `validate_identifiers(table, schema, geom)` is line 1 of each builder + `validate_identifiers(*columns)`; verified by `TestBuildGeojsonSql`/`TestBuildTextSql` injection tests asserting `InvalidIdentifierError` before any SQL is sent |
| T-44-01b | Tampering (injection via numeric/options args) | `max_decimal_digits`, options bitmask | mitigate | Passed as `%s` bind params, never string-interpolated; options is a computed `int` from two bools — no caller string reaches the SQL text |
| T-44-01c | Information disclosure via `filter=` raw fragment | `as_geojson`/`as_text` `filter` | accept | `filter` is a documented raw-SQL escape hatch (consistent with the whole spatial surface); caller owns the fragment; no identifier path bypasses the line-1 guard |
</threat_model>
